  • ids are prefixed "sidefn:" instead of "fn:", so the in-text marker's link (href="#fn:...") always jumps to the bottom copy, never the sidenotes column. On narrow screens the sidenotes copy is hidden entirely (CSS) and the bottom list is the only one visible, so nothing doubles up there. Shared by _layouts/post.html (one post, its own page) and _layouts/feed.html (several posts stacked on one page, e.g. /latest/). Required params: post - the post/page object to render uid - a string unique to this post ON THIS PAGE.
